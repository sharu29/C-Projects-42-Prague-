# libft

`libft` is a custom C library that implements a set of standard C functions, as well as some additional functions not found in the C standard library. The goal of this project is to recreate these functions from scratch, following their behavior as defined in their man pages. 

## Part 1 - Libc Functions

In this part, we reimplement various functions from the C standard library (`libc`) with the `ft_` prefix. These functions cover a range of tasks, including string manipulation, memory handling, and character checking. Some of the functions implemented include:

- `ft_isalpha`
- `ft_isdigit`
- `ft_strlen`
- `ft_memset`
- `ft_memcpy`
- `ft_strchr`
- `ft_strrchr`
- `ft_atoi`
- And many more...

## Part 2 - Additional Functions

In this part, we implement functions that are either not present in the C standard library or are present in a different form. These functions include:

- `ft_substr` – Creates a substring from a string.
- `ft_strjoin` – Concatenates two strings.
- `ft_strtrim` – Trims specified characters from a string.
- `ft_split` – Splits a string into an array of strings based on a delimiter.
- `ft_itoa` – Converts an integer to a string.
- And others...
